# 💅 Sistema de Agenda para Manicurista

Sistema web desarrollado en Django para la gestión de citas, pagos y seguimiento de clientes.

## 🚀 Funcionalidades

- Gestión de citas por día
- Registro de pagos
- Cálculo de saldo pendiente
- Visualización de clientes deudores
- Conteo de citas sin precio definido
- Eliminación de citas con confirmación visual

## 🛠 Tecnologías utilizadas

- Python
- Django
- HTML5
- CSS3
- SQLite

## 📊 Objetivo del proyecto

Desarrollar una solución simple y funcional para la gestión diaria de una manicurista, enfocada en usabilidad y claridad visual.

## 📌 Estado

Proyecto funcional en uso real.
